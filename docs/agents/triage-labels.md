# Triage labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| Needs evaluation | `needs-triage` | Maintainer needs to evaluate |
| Waiting for information | `needs-info` | Waiting on the reporter |
| Ready for implementation | `ready-for-agent` | Fully specified for an agent |
| Needs human implementation | `ready-for-human` | Requires human implementation |
| Will not implement | `wontfix` | Will not be actioned |

Create a missing label when needed. Specs synthesized with to-spec receive `ready-for-agent`.
